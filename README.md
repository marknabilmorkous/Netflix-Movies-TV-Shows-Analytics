# Netflix Movies & TV Shows Analytics Dashboard

An interactive dashboard designed to analyze global content trends, distribution patterns, genre popularity, and rating classifications across Netflix's catalog of movies and TV shows.

---

## 📋 Project Overview

This analytics project delivers end-to-end insights into Netflix's expanding content library. By examining content distribution across countries, release years, ratings, and genres, this dashboard helps visualize how streaming media has evolved over time and how content varies between Movies (68.4%) and TV Shows (31.6%).

---

The dashboard provides a high-level view of global media trends along with detailed title search capabilities:

### 1. Catalog Breakdown & Key Metrics
* **Total Content Distribution:** Visualizes the catalog split between Movies (4,265 titles / 68.42%) and TV Shows (1,969 titles / 31.58%).
* **Content Details Header:** Features dynamic lookup card displaying selected title metadata (Type, Duration, Rating, Date Added, Release Year, Genre, and Description synopsis).

### 2. Rating & Geographic Insights
* **Ratings Distribution:** Analyzes titles grouped by maturity ratings, highlighting **TV-MA** (2,027 titles) and **TV-14** (1,698 titles) as the largest content categories.
* **Geographical Map:** Interactive world map mapping total movies and TV shows produced across countries (including United States, Japan, India, UK, Spain, and more).

### 3. Genre & Timeline Trends
* **Top 10 Genres:** Horizontal bar chart displaying leading genres such as Documentaries (299), Stand-Up Comedy (273), Dramas/International Movies (248), and Comedies.
* **Historical Growth Trend:** Area chart mapping catalog expansion over time from early release years up to recent additions (peaking around 2019-2021).
